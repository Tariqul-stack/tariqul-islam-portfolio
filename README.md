# 🧑‍💻 Tariqul Islam — Personal Portfolio

A modern, responsive personal portfolio website showcasing my projects, skills, and experience as a Full-Stack Developer.

🌐 **Live Site:** [https://tariqul-islam-portfolio.vercel.app](https://tariqul-islam-portfolio.vercel.app)

---

## ✨ Features

- 🎨 **Dark / Light Theme** — Smooth theme toggle with system preference support
- 💫 **Animations** — Framer Motion powered page transitions and scroll animations
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop
- 🖼️ **Project Showcase** — Auto-sliding image carousel with filter by category
- ⚡ **Fast Performance** — Built with Next.js App Router for optimal loading
- 🎯 **Custom Cursor** — Interactive cursor glow effect

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Next.js (App Router) | React framework with SSR |
| Tailwind CSS | Utility-first styling |
| Framer Motion | Animations and transitions |
| React Icons | Icon library |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Tariqul-stack/tariqul-islam-portfolio.git
cd tariqul-islam-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
